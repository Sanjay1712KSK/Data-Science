## 🚀 Getting Started

### Prerequisites

```bash
# Python 3.7 or higher
python --version

# Recommended: Use virtual environment
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
```

### Installation

Clone the repository:
```bash
git clone https://github.com/Sanjay1712KSK/Data-Science-21CSS303T.git
cd Data-Science-21CSS303T
```

Install required packages:
```bash
pip install -r requirements.txt
```

Or install manually:
```bash
pip install jupyter pandas numpy scikit-learn matplotlib seaborn scipy requests beautifulsoup4
```

### Running the Code

**For Jupyter Notebooks:**
```bash
jupyter notebook
```
Navigate to any `.ipynb` file and run the cells interactively.

**For Python Scripts:**
```bash
python Assignments/Unit1Assignment.py
python Datasets/visualize.py
python End\ Sem\ Exam\ Prep/practice/datawrangling.py
```

**For Data Visualization Practice:**
```bash
cd End\ Sem\ Exam\ Prep/practice/
python matplotlibandseabornprac.py  # Generates visualization screenshots
```
